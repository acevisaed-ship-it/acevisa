Standard service wording for the invoice front.

Staff select the lines that apply. Nothing else is promised. Optional line 5 for visit visa is left as a company decision (see clause 7.3).

Visit visa
1. Document assessment (completeness and format check)
2. Visa application file preparation
3. Interview preparation
4. Customer services during the application
5. [Post-application correspondence between the embassy and the Client — include only if this is a promised service]

Study visa
1. Counselling and programme shortlisting
2. Admission application preparation and submission
3. Document assessment and checklist
4. Visa application file preparation
5. Interview preparation
6. Customer services during the application

Other visa / documents
1. Document assessment
2. Application file or document preparation (state which)
3. Appointment assistance (if included)
4. Attestation or translation coordination (if included)

Language tests
1. Test booking or voucher supply (state provider and test)
2. Class or guidance sessions (state number, if included)
